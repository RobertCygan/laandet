# User-provided G-PSI logo intro

`intro.webm` (VP9) and `intro.mp4` (H.264) were supplied by the project owner for this project. Both are unmodified 1080 × 1080, seven-second versions of the same silent G-PSI GovTech Solutions logo animation. They are not AI-generated Lånndet marketplace inventory.

The web app serves the WebM source with MP4 fallback. The standalone exporter embeds both original files as data URLs, so the downloaded HTML needs no video files alongside it. The intro plays on document opening and does not replay during internal navigation. A visible skip button and Escape key dismiss it; reduced-motion preference bypasses video loading, and playback failure falls through to the application.
