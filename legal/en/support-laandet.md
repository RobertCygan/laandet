# Support Laandet

> **Informational translation.** The Norwegian version of this document is the legally binding one. If the two versions differ, the Norwegian text prevails.

Laandet is being developed as a local service for Steigen. The platform is free to use. If you would like
to contribute towards server costs, operation and further development, you can support the project voluntarily.
All contributions are optional.

## This is always free

- Creating an account
- Posting listings
- Giving things away
- Sending requests and messages

Laandet takes no commission. There is no subscription. You get exactly the same service whether you
support us or not.

## What does it cost to run Laandet?

The money goes to

- server and database,
- backups,
- sending email,
- domain name,
- security and further development.

You can see actual costs and contributions on the [Transparency](/apenhet) page. There we only show
figures we have checked.
