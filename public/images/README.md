# Original project imagery

`hero.webp` and `equipment.webp` were generated for this project with OpenAI image generation on 2026-10-21. No competitor or stock listing photographs were sourced. They depict fictional settings, not real rental inventory. AI generation does not establish exclusive rights or guarantee that equipment resembles no existing product. No affiliation with an equipment manufacturer is claimed.

`equipment-1.webp` through `equipment-18.webp` are web-optimized crops from the original 3 × 6 generated equipment sheet, in the same order as `data/demoListings.ts`. All image exports use WebP. The originals remain outside the checkout in `/workspace/generated_images` in this prepared machine; the application needs only these committed exports.

Logo, delivery illustration and illustrative maps are original vector artwork in the source. Product photographs are single images; we do not pretend to have additional views of a nonexistent product. The detail image opens a keyboard-accessible lightbox.
